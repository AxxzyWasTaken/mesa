# M4 Max Mesa benchmarks, 17 Nov 2026

Benchmark sources, runner scripts and raw output for aurora-silicon/mesa #417, #418 and the M4 Max 2x compression PR.
Hardware: MacBook Pro 16" M4 Max (J616C, T6041, 32-core GPU), on battery, fans on SMC automatic.
Every build is aurora-wip 57df4db8 plus the PR, built in one build dir with the same options; builds alternate run by run.
`summary-full.txt` has the medians; `raw/` has every run.
